# 🏎️ Flappy T — Ferrari SF90 Stradale Edition

Un remaster web moderne de **Flappy Bird** baptisé **Flappy T**, dans lequel vous pilotez une **Ferrari SF90 Stradale** (Rosso Corsa / Pack Assetto Fiorano) à travers les portiques de chicane d'un circuit nocturne.

## ✨ Fonctionnalités
- **Ferrari SF90 Stradale vectorielle** dessinée sur Canvas HTML5 (phares Matrix LED avec faisceau lumineux, prise d'air latérale triangulaire, écusson Scuderia Ferrari, étriers Giallo Modena, jantes forgées 5 branches animées et flammes d'échappement V8 bi-turbo hybride).
- **Effets sonores synthétisés** via Web Audio API (son de boost V8, passage de portique et crash).
- **Difficulté progressive** et sauvegarde du meilleur score (`localStorage`).
- **Compatible PC & Mobile** (`Espace`, `Flèche Haut`, `Clic` ou `Tactile`).

## 🚀 Lancer le jeu
Ouvrez simplement `index.html` dans votre navigateur web.
